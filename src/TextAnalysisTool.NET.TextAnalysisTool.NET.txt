========================================
== TextAnalysisToolEnhance Documentation ==
========================================


-----------------------------
-- Section: Brief Tutorial --
-----------------------------

If you're not already viewing this document with TextAnalysisToolEnhance, please
do so by running the application and choosing the Help | Documentation menu
item.  Having done so, you should be seeing this documentation file displayed
in the top part of the application's window along with a few handy filters in
the bottom part of the window.  To quickly see what section headings this
document has, click the "Section:" filter to enable it - and while you're at it
go ahead and enable the next filter down, too: "Marked by marker 1".  Notice
how all lines that don't match the filters you just enabled have been dimmed.
Click anywhere in the line display to give it focus and then hit the Space bar
a few times to cycle forward through all the matching lines (use Shift+Space to
cycle backward).  To take things a step further, hit Ctrl+H or choose the View
| Show Only Filtered Lines menu option.  Because you're now seeing only the
lines you're interested in, it's easy to avoid getting bogged down by spurious
details.  Use the arrow keys to highlight the section on command-line
parameters (it's near the bottom) and hit Ctrl+H again to view the selected
line in the context of its surroundings.  Explore the power of this interface
by enabling and disabling some of the other sample filters, then read the rest
of this document to find out how to take advantage of more neat features!


-----------------------
-- Section: Overview --
-----------------------

The Problem: For those times when you have to analyze a large amount of textual
data, picking out the relevant line(s) of interest can be quite difficult.
Standard text editors usually provide a generic "find" function, but the
limitations of that simple approach quickly become apparent (e.g., when it is
necessary to compare two or more widely separated lines, or correlate multiple
asynchronous log streams).  Some more sophisticated editors allow you to
"bookmark" lines of interest, but bookmarked lines are often lost among thousands
of unrelated lines.

The Solution: TextAnalysisToolEnhance - a high-performance application designed
from the start to excel at viewing, searching, navigating, and merging large
files quickly and efficiently.  TextAnalysisToolEnhance provides a view of your data
that you can easily manipulate through filters, markers, and multi-stream log
merging to display exactly the information you need.

Filters: Before displaying the lines of a file, TextAnalysisToolEnhance passes the
lines through a set of user-defined filters, dimming or hiding all lines that
do not satisfy any of the filters.  Filters can match text, regular expressions,
marker types, or line number ranges.  Text and background colors can be associated
with each filter so matching lines stand out clearly.  In addition to "including"
filters that isolate lines you want to see, "excluding" filters can suppress lines
you do not want to see.

Refine Filter: A second-layer, real-time keyword filter located above the filter
list window.  It performs an immediate AND filter on top of the already-
filtered lines without requiring you to create temporary filters in the filter list.

Marked Lines Window: A dedicated window that aggregates all lines that have been
marked with any of the 8 marker types.  Double-clicking any line in this window
instantly jumps to and highlights that line in the main line display.

Multi-File & Archive Merging: TextAnalysisToolEnhance natively understands .zip,
.7z, and .gz archives without pre-extraction.  It can merge multiple log files
and archives, automatically detecting timestamps and sorting lines in strict
chronological order with color-coded source tags.

Summary: Speed, reliability, and precision are the core tenets of
TextAnalysisToolEnhance.  It supports drag-and-drop, Windows Explorer "Send to"
integration, clipboard importing, and multiple encodings (ANSI, UTF-8, Unicode,
GB18030).


---------------------------------
-- Section: The User Interface --
---------------------------------

Display
-------

Line Display: Shows the active file or merged lines.  Each line shows its
original line number, marker indicators, and custom filter colors.  When you
select multiple lines, context menu actions (such as hiding the selected range)
affect the full selection.

Filter Display: Shows all configured filters.  Filters can be toggled on/off,
rearranged via drag-and-drop, and edited by double-clicking or pressing Enter.
Double-clicking a line number filter opens the Line Number Range editor.

Marked Lines Display: Located in a dedicated pane adjacent to the line display.
It automatically collects and displays all lines that have been tagged with any
of the 8 marker colors.  Double-clicking any item in this pane immediately
scrolls the main line display to that exact line.

Refine Filter Box: Located above the filter list window.  Allows typing
keywords to immediately filter the active view in real time (press Ctrl+E to
focus, Ctrl+K to clear).

Status Bar: Shows source file details, selection counts, filtered line counts,
total line counts, and zoom level.

Context Menus (Right-Click)
---------------------------

Right-clicking on lines in the main line display provides smart context actions:
- Multi-Line Selection: If two or more lines are selected, shows "Hide Lines X to Y"
  to hide all lines between the minimum and maximum selected line numbers.
- Single-Line Selection: Shows "Hide Lines Before This" and "Hide Lines After This".
- Plug-in Actions: Installed plug-ins can add actions (e.g. "Filter by PID 1234",
  "Filter by tag ActivityManager", or "More Android Filter Options").
- Toggle Marker: Submenu to toggle Markers 1 through 8 on the selected line(s).


Keyboard Shortcuts
------------------

Space          Scrolls to the next line matching any enabled filter
Shift+Space    Scrolls to the previous line matching any enabled filter
1-8            Scrolls to the next line tagged with the corresponding marker
Shift+1-8      Scrolls to the previous line tagged with the corresponding marker
Ctrl+1-8       Toggles the corresponding marker for selected line(s)
Ctrl+E         Focuses the Refine Filter text box
Ctrl+K         Clears the Refine Filter text box

A-Z            Scrolls to the next line matched by the corresponding filter (1st-26th)
Shift+A-Z      Scrolls to the previous line matched by the corresponding filter

-- Section: Open and Merge Logs (Archives & Multi-File Support) --
--------------------------------------------------------------------

TextAnalysisToolEnhance includes built-in support for reading compressed archives
and merging multiple log streams:

1. Supported Formats:
   - Plain text and log files (.txt, .log, .csv, etc.)
   - Compressed archives: .zip, .7z, and .gz

2. Invoking Open & Merge:
   - File -> Open...: Select multiple files or a single archive.
   - Drag & Drop: Drag multiple files or an archive into the window.
   - Windows "Send to": Select files in Windows Explorer, right-click, and choose
     "Send to -> TextAnalysisToolEnhance".
   - Command Line: Pass multiple paths or an archive path to the executable.

3. The Open / Merge Logs Dialog:
   - Archive Exploration: Archives are inspected directly, displaying all text
     members inside without extracting them to disk first.
   - Timestamp Synchronization: When multiple files are merged, timestamps are
     parsed across all sources and sorted in chronological order.
   - Source Tagging: Each line in the merged output is prefixed with a colored
     source tag (e.g. "[main.log]", "[system.log]") to easily identify its origin.
   - Direct Open: Double-clicking any single file in the list opens it immediately.


-------------------------------------------------------------
-- Section: Line Number Filtering and Range Hiding --
-------------------------------------------------------------

Line number filters allow restricting the view to specific portions of a log:

1. Creating Line Number Filters:
   - From the Context Menu:
     * Right-click a line -> "Hide Lines Before This"
     * Right-click a line -> "Hide Lines After This"
     * Select multiple lines -> Right-click -> "Hide Lines X to Y"
   - From the Filter Dialog:
     * Filters -> Add New Filter... -> Select "Line number range"

2. Editing in FilterDialog:
   Double-clicking any line number filter opens the "Line number range" editor:
   - Start line: The lower boundary line number.
   - End line: The upper boundary line number.
   - Leave either empty for an unbounded range.

3. Excluding Semantics:
   - Range [Start=160, End=180]:
     * Excluding Checked: Hides lines 160 to 180.
     * Excluding Unchecked: Displays only lines 160 to 180.
   - Start Only [Start=160, End empty]:
     * Excluding Checked: Hides lines before 160 (displays line 160 onwards).
     * Excluding Unchecked: Displays only lines before 160.
   - End Only [Start empty, End=180]:
     * Excluding Checked: Hides lines after 180 (displays lines up to 180).
     * Excluding Unchecked: Displays only lines after 180.

4. Dynamic Description:
   The filter description automatically updates in real time as you edit line
   numbers or toggle the Excluding checkbox, while preserving custom text if
   manually edited.


-----------------------
-- Section: Plug-ins --
-----------------------

TextAnalysisToolEnhance supports external plug-ins implemented in .NET assemblies
matching "TATPlugin_*.dll" placed in the application directory.

Plug-ins can provide:
1. Custom File Decoders: Decode binary, compressed, or proprietary file formats.
2. Context Menu Filter Generators: Inspect right-clicked lines and provide
   specialized filter generation (e.g. filtering by Android logcat PID or Tag).
3. Custom Colors & Palettes: Plug-ins can specify foreground and background
   colors, prompt for colors on the fly, or assign colors from curated palettes.
4. Plug-in Settings: Implement GetSettingsDialog() to provide a dedicated
   configuration form accessible via Edit | Plug-in Settings | [Plug-in Name].

The included AndroidLog plug-in (TATPlugin_AndroidLog) demonstrates:
- Extracting PID and Tag from Android logcat lines.
- Consistent random color assignment from a 24-color high-contrast palette.
- Fixed custom color configuration with instant preview.
- Settings persistence in the Windows Registry.


----------------------------------------
-- Section: Regular Expression Syntax --
----------------------------------------

TextAnalysisToolEnhance uses the standard .NET Framework regular expression engine
(System.Text.RegularExpressions.Regex), supporting:
- Quantifiers (*, +, ?, {n,m})
- Character classes (\d, \w, \s, [a-z], [^0-9])
- Anchors (^, $, \b, \B)
- Grouping and alternation ((abc|def), (?:non-capturing))
- Lookaround assertions ((?=...), (?!...), (?<=...), (?<!...))

Right-clicking the "Regular expression" checkbox in the Filter or Find dialog
opens the official Microsoft Regex documentation in your default browser.


--------------------------------------
-- Section: Command-Line Parameters --
--------------------------------------

Usage:
TextAnalysisToolEnhance.exe [Files...] [/Filters:FilterFile] [/Config:ConfigFile]
                         [/Line:LineNumber] [/Clipboard] [/SendTo:add|remove]

Parameters:
   Files...          One or more text files or archives (.zip, .7z, .gz) to open.
                     If multiple files or an archive are specified, the Open /
                     Merge Logs dialog will open automatically.
   @listfile.txt     Reads paths from a text file (one path per line).
   /Filters:Path     Loads and appends filters from a .tat file.
   /Config:Path      Imports preferences from an XML configuration file.
   /Line:Number      Scrolls to and highlights the specified line number.
   /Clipboard        Loads text directly from the Windows clipboard.
   /SendTo:add       Registers TextAnalysisToolEnhance in the Windows "Send to" menu.
   /SendTo:remove    Removes TextAnalysisToolEnhance from the Windows "Send to" menu.

Examples:
   TextAnalysisToolEnhance.exe "C:\logs\main.log"
   TextAnalysisToolEnhance.exe "C:\logs\bugreport.zip"
   TextAnalysisToolEnhance.exe "C:\logs\a.log" "C:\logs\b.log"
   TextAnalysisToolEnhance.exe /Filters:"C:\rules\audio.tat" /Line:1200 "C:\logs\main.log"
   TextAnalysisToolEnhance.exe @"C:\temp\files.txt"


---------------------------------
-- Section: Configuration File --
---------------------------------

Preferences can be exported and imported as XML configuration files from the
Edit | Preferences... dialog using the "Export..." and "Import..." options
under the "More >>" menu button.


------------------------
-- Section: Encodings --
------------------------

TextAnalysisToolEnhance detects and applies character encodings in the following
priority order:
  1) Byte order marks (BOM) in UTF files
  2) The encoding chosen via View | Encoding menu
  3) The "Default Encoding" setting in Edit | Preferences...
  4) The system default ANSI code page
