==   TextAnalysisToolEnhance 内置指南   ==

-----------------------------
-- 章节: 快速上手教程 --
-----------------------------

如果您现在已经在 TextAnalysisToolEnhance 中查阅本文档，您应该能在程序主窗口
的上半部分看到本指南内容，并在下半部分的过滤器列表中看到几个预设的示例过滤器。
为了快速概览本指南的章节导航，请点击勾选底部的“章节:”过滤器以启用它；同时也可
以顺手启用其下方的“第 1 种标记”过滤器。
此时您会发现：所有未匹配上述过滤器的行全部自动变暗（淡化展示）。
鼠标点击上方任意文本区域使行列表获得焦点，然后连续按空格键（Space），即可在所有
匹配的行之间依次快速跳转浏览（按 Shift+Space 可反向跳转）。
想要更进一步？请按下快捷键 Ctrl+H，或点击菜单“视图 | 仅显示过滤行”。
此时界面将只保留您所关注的关键行，排除所有无关干扰！
利用键盘上下方向键浏览到底部的命令行参数章节，再次按下 Ctrl+H 即可随时切回全局上下文。
试着勾选和禁用其他示例过滤器，感受高效率过滤的魅力，然后继续阅读下文了解更多强大功能！


-----------------------
-- 章节: 概述 --
-----------------------

面临的问题：在排查复杂软件故障（如 Android 系统日志、服务崩溃、大规模分布式链路）时，
日志量往往动辄数十万甚至上百万行，大海捞针极其困难。常规编辑器自带的查找功能局限性很大，
很难对比相隔甚远的多行上下文；普通的行书签也容易被淹没在海量日志中。

解决方案：TextAnalysisToolEnhance —— 一款专为极速浏览、多维过滤、行号导航与多日志
合并排序而生的高性能日志分析神器。通过多层过滤器、颜色高亮、独立书签面板与时间戳对齐，
让您按需定制并精确聚焦核心信息。

过滤器 (Filters)：支持普通字符串、正则表达式、标记类型（Marker）以及行号范围规则。
每个过滤器均可自由搭配前景色与背景色。除“包含(Including)”规则外，更支持“排除(Excluding)”
规则，用于精准剔除已知干扰日志。

精炼过滤 (Refine Filter)：位于过滤器列表窗口上方的第二层即时关键字过滤引擎。在下方过滤器已
筛选出的结果基础之上，输入关键字即可毫秒级即时取交集（AND 逻辑），配合 Ctrl+E 与 Ctrl+K
快捷键，无需反复新建或删除临时过滤器。

独立标记书签窗口 (Marked Lines Display)：专用的汇总停靠面板，实时收集所有打上数字标记
（Marker 1~8）的行。双击其中任意一行，主窗口立即自动同步平滑跳转并高亮该行。

多日志合并与压缩包直读 (Open & Merge Logs)：无需预先解压即可直接查看 .zip, .7z, .gz
压缩包内的日志成员。支持将来自不同源（如 main.log、system.log、kernel.log）的多个文件
按微秒级时间戳严格升序交错合并，并附带专属来源标签（[source_tag]）。


---------------------------------
-- 章节: 用户界面 --
---------------------------------

核心面板
--------

行列表显示区 (Line Display)：显示当前打开的日志或多源合并后的排好序的文本行。
每行左侧显示原始行号与书签标记指示符，并按最高优先级的匹配过滤器进行颜色高亮。

过滤器列表 (Filter Display)：管理当前所有过滤规则。点击复选框即时启用/禁用，双击或按
回车键即可编辑规则。双击行号过滤器可直接唤出“行号范围编辑”界面。支持鼠标拖拽调整规则顺序。

独立标记书签面板 (Marked Lines Display)：位于主界面右侧或下方的独立窗口，自动将您在
日志中打上颜色标记的所有行集中展现，双击任意行即可令主视图瞬间定位。

精炼输入框 (Refine Filter Box)：位于过滤器窗口上方的即时过滤框。随时按 Ctrl+E 输入关键字即时
过滤，按 Ctrl+K 一键清空。

状态栏 (Status Bar)：实时显示当前文件名、选中行数 (Sel)、匹配行数 (Fil)、总行数 (Total)
以及缩放百分比。

右键快捷菜单 (Context Menu)
---------------------------

在主日志行列表上右键点击，提供智能化上下文操作：
- 多行选中状态：若选中了两行或两行以上，顶部动态出现“Hide Lines {min} to {max}”，
  点击后一键隐藏选中的最小行到最大行之间的全部干扰内容。
- 单行选中状态：提供“Hide Lines Before This”（隐藏此行之前）与“Hide Lines After This”（隐藏此行之后）。
- 插件快捷过滤：已安装插件动态识别当前行内容（如 Android 日志的“Filter by PID”与“Filter by tag”）。
- Toggle Marker 子菜单：为所选行快速赋予 1~8 号标记。


常用快捷键
----------

Space          向下跳转到下一个匹配任意过滤器的行
Shift+Space    向上跳转到上一个匹配任意过滤器的行
1 ~ 8          向下跳转到下一个被打上对应编号标记的行
Shift+1 ~ 8    向上跳转到上一个被打上对应编号标记的行
Ctrl+1 ~ 8     为当前选中行快速切换打上/取消对应的标记
Ctrl+E         光标快速聚焦到过滤器窗口上方的 Refine 精炼过滤框
Ctrl+K         一键清空 Refine 过滤框内容
Ctrl+H         切换“仅显示过滤行”与“显示全量行”视图
Ctrl+F         呼出查找对话框
F3 / Shift+F3  向下 / 向上查找下一个匹配项
A ~ Z          跳转到第 1 到 26 个过滤器匹配的下一行


--------------------------------------------------------------------
-- 章节: 多日志合并与压缩包直读 (Open & Merge Logs) --
--------------------------------------------------------------------

TextAnalysisToolEnhance 具备原生的压缩包解析与跨日志时间戳并发归并能力：

1. 支持的格式：
   - 各种文本日志 (.txt, .log, .csv 等)
   - 常用压缩归档：.zip, .7z, .gz

2. 触发方式：
   - 文件菜单：点击“文件 | 打开...”，按住 Ctrl 选中多个文件或单个 .zip 压缩包。
   - 拖拽打开：从桌面或文件夹中拖拽多个文件或压缩包放开到主窗口。
   - 资源管理器右键：右键文件选择“发送到 -> TextAnalysisToolEnhance”。
   - 命令行：直接在命令行传入多个文件路径或压缩包路径。

3. Open / Merge Logs 弹框核心功能：
   - 免解压预览：直接探测并列出压缩包内的全部日志文本成员，无需解压至磁盘。
   - 时间戳智能对齐：自动识别多种主流时间戳格式，并发解析并按绝对时间严格升序排序。
   - 来源标签染色：合并后的每一行前置彩色 [源文件名] 标签，多端日志交互一清二楚。
   - 单选直开：双击列表中的任一成员文件即可直接以单文件模式极速打开。


-------------------------------------------------------------
-- 章节: 行号范围过滤与多选隐藏 (Line Number Range) --
-------------------------------------------------------------

行号过滤器用于锁定日志排查的特定时间窗或代码块范围：

1. 快捷生成途径：
   - 选中多行 -> 右键 -> 点击“Hide Lines {min} to {max}”
   - 单行右键 -> “Hide Lines Before This” 或 “Hide Lines After This”
   - 过滤器菜单 -> “添加新过滤器...” -> 过滤器类型选择“Line number range”

2. 双击编辑行号规则：
   双击底部过滤器列表中的行号过滤器，即可在弹框中直接修改起始行号与终止行号：
   - Start line (起始行号)：范围下边界。
   - End line (终止行号)：范围上边界。
   - 任一留空表示不设单侧边界。

3. Excluding（排除）语义规则：
   - 闭区间 [Start=160, End=180]：
     * 勾选 Excluding：隐藏 160 至 180 之间的行。
     * 取消 Excluding：仅保留显示 160 至 180 之间的行。
   - 单边起始 [Start=160, End留空]：
     * 勾选 Excluding：隐藏 160 之前的行（保留 160 之后，即 Hide before）。
     * 取消 Excluding：仅保留显示 160 之前的行。
   - 单边终止 [Start留空, End=180]：
     * 勾选 Excluding：隐藏 180 之后的行（保留 180 之前，即 Hide after）。
     * 取消 Excluding：仅保留显示 180 之后的行。

4. 描述动态同步：
   修改行号或切换 Excluding 时，下方 Description 文本框即时联动自动同步；
   若您手动输入了自定义业务备注，则会自动予以保留。


-----------------------
-- 章节: 插件系统与 Android 日志 --
-----------------------

程序支持通过放置在 exe 同目录下的“TATPlugin_*.dll”进行功能扩展。

内置 AndroidLog 插件特色能力：
1. 智能快选：右键点击 Android logcat 行，一键提取 PID 与 Tag 并生成过滤规则。
2. 调色板系统：
   - 指定固定色：自定义醒目前景色（默认预设清爽蓝色 PID 与绿色 Tag，无底色）。
   - 随机色彩模式：从精心筛选的 24 色高对比度鲜艳色盘中自动分配。开启同一 Tag/PID 保持相同颜色
     后，相同 Tag 永远保持相同颜色，多个不同 Tag 缤纷区分、对比强烈。
3. 插件设置：点击“编辑 | 插件设置 | AndroidLogPlugin”打开可视化设置窗口，支持实时效果预览，
   设置自动保存到 Windows 注册表中。


--------------------------------------
-- 章节: 命令行参数 --
--------------------------------------

使用格式：
TextAnalysisToolEnhance.exe [文件列表...] [/Filters:规则文件] [/Config:配置文件]
                            [/Line:行号] [/Clipboard] [/SendTo:add|remove]

参数说明：
   文件列表...       传入一个或多个文本或压缩包路径。若传入多个文件或压缩包，
                     自动进入 Open / Merge Logs 弹框。
   @listfile.txt     从文本文件中按行批量读取目标文件路径。
   /Filters:路径     启动时自动载入并应用 .tat 过滤器规则文件。
   /Config:路径      启动时导入指定的 XML 首选项配置文件。
   /Line:数值        打开后自动滚动并高亮定位到指定行号。
   /Clipboard        直接将 Windows 剪贴板文本作为日志源载入。
   /SendTo:add       静默将本程序添加至 Windows“发送到 (Send to)”菜单。
   /SendTo:remove    静默从 Windows“发送到”菜单中移除快捷方式。

示例：
   TextAnalysisToolEnhance.exe "D:\logs\main.log"
   TextAnalysisToolEnhance.exe "D:\logs\bugreport.zip"
   TextAnalysisToolEnhance.exe "D:\logs\main.log" "D:\logs\system.log"
   TextAnalysisToolEnhance.exe /Filters:"D:\rules\audio.tat" /Line:1200 "D:\logs\main.log"
